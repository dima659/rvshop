# RAVOUT SHMOT — Telegram Mini App

Магазин вещей из Китая: каталог, поиск по фото и описанию, заявки, корзина и заказы, профиль, админ-панель.
Приложение прокручивается только вверх и вниз. Сервер и бот в одном файле `server.py`, без зависимостей (нужен Python 3.9+).

## Запуск

1. Создайте бота в @BotFather и скопируйте токен.
2. Нужен публичный HTTPS-адрес (Telegram другие не принимает). Варианты: VPS с Caddy или nginx, Render, Railway, Fly.io.
   Для проверки с компьютера: `cloudflared tunnel --url http://localhost:8080`.
3. Запустите:
   ```
   BOT_TOKEN=123:ABC WEBAPP_URL=https://ваш-адрес ADMIN_IDS=111,222 python3 server.py
   ```
4. Узнайте свой Telegram ID: напишите боту `/id` и впишите его в `ADMIN_IDS` (через запятую для нескольких админов), затем перезапустите.
5. Откройте бота, нажмите «Магазин» или `/start`. Админ увидит в профиле пункт «Админ-панель».

## Что умеет

- **После загрузки** показывается окно подписки на live-канал https://t.me/Ravoutshmotlive (один раз).
- **В профиле** кнопка основного канала https://t.me/ravoutshmot.
- **Поиск:** по описанию ищет в каталоге, по фото (камера или галерея) создаёт заявку. Не нашли в каталоге: заявка и по тексту.
- **Заявки и заказы** приходят админам сообщением в Telegram. Смена статуса и ответ в админке уходят клиенту в Telegram.
- **Админ-панель:** товары (добавить, изменить, скрыть, удалить, фото), заявки (фото, статус, ответ), заказы (статус).
- В каталоге 4 примера товаров без цен («Цена по запросу»): замените их в админ-панели.

## Данные и безопасность

- База `shop.db` (SQLite) и фото в папке `uploads/` лежат рядом с `server.py`: делайте их резервные копии.
- Каждый запрос проверяется подписью Telegram (HMAC), админ-права определяет сервер по `ADMIN_IDS`.
- Оплаты в приложении нет: заказ уходит админу, дальше вы договариваетесь с клиентом сами.
