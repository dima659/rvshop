# RAVOUT SHMOT — Telegram Mini App

Магазин вещей из Китая: каталог, поиск по фото и описанию, заявки, корзина и заказы, профиль, админ-панель.
Приложение прокручивается только вверх и вниз. Сервер и бот в одном файле `server.py`, без зависимостей (нужен Python 3.9+).

## База данных (чтобы ничего не пропадало)

Все данные (товары, заявки, заказы и **фото**) хранятся в PostgreSQL, а не на сервере Render. Перезапуски и новые деплои их не стирают.

1. Зарегистрируйтесь на neon.tech (бесплатно), создайте проект и скопируйте строку подключения (Connection string, вида `postgresql://...?sslmode=require`).
2. Вставьте её в Render в переменную `DATABASE_URL`.

Подойдёт и Supabase, и платный Render Postgres. Таблицы создаются сами при первом запуске. Без `DATABASE_URL` используется локальный файл SQLite: годится только для проверки на компьютере.

## Проверка подписки на live-канал

После загрузки приложение показывает окно подписки на https://t.me/Ravoutshmotlive и не пускает дальше, пока человек не подпишется (кнопки «Подписаться на Telegram» и «Я подписался»; проверка также срабатывает при возврате в приложение). Оформить заказ и заявку без подписки нельзя, это проверяет и сервер. Админы из `ADMIN_IDS` проходят без проверки. Чтобы проверить окно подписки со своего админского аккаунта, временно добавьте в Render переменную `CHECK_ADMINS=1` (после проверки удалите). Статус подписки проверяется заново при каждом открытии приложения.

**Обязательно:** добавьте вашего бота **администратором** в канал @Ravoutshmotlive (иначе Telegram не даёт боту проверять подписчиков). Если бот не админ, проверка не может работать, и приложение пускает всех, чтобы не заблокировать магазин; причина пишется в лог.

## Запуск на Render

1. Создайте бота в @BotFather и скопируйте токен.
2. Загрузите содержимое этой папки в репозиторий на GitHub.
3. На render.com: **New → Blueprint**, выберите репозиторий (или создайте Web Service вручную: Build `pip install -r requirements.txt`, Start `python server.py`).
4. Введите `BOT_TOKEN` и `DATABASE_URL`. `ADMIN_IDS` пока оставьте пустым.
5. Когда сервис запустится, напишите боту `/id`, он пришлёт ваш Telegram ID. Впишите его в `ADMIN_IDS` (несколько через запятую), сервис перезапустится.
6. Откройте бота и нажмите «Магазин» или `/start`. В профиле у админа появится «Админ-панель».

Адрес приложения Render подставляет сам. Бот работает через вебхук: Telegram сам будит сервис, даже если на бесплатном тарифе он «заснул» (первый ответ после сна может занять до минуты).

## Запуск на своём сервере

`BOT_TOKEN=... DATABASE_URL=postgresql://... WEBAPP_URL=https://ваш-адрес ADMIN_IDS=111,222 python3 server.py` (нужен HTTPS-адрес и Python 3.9+).

## Что умеет

- **После загрузки** показывается окно подписки на live-канал https://t.me/Ravoutshmotlive (один раз).
- **В профиле** кнопка основного канала https://t.me/ravoutshmot.
- **Поиск:** по описанию ищет в каталоге, по фото (камера или галерея) создаёт заявку. Не нашли в каталоге: заявка и по тексту.
- **Заявки и заказы** приходят админам сообщением в Telegram. Смена статуса и ответ в админке уходят клиенту в Telegram.
- **Админ-панель:** товары (добавить, изменить, скрыть, удалить, фото), заявки (фото, статус, ответ), заказы (статус).
- В каталоге 4 примера товаров без цен («Цена по запросу»): замените их в админ-панели.

## Данные и безопасность

- Фото хранятся в базе вместе с остальными данными. Делайте резервные копии базы средствами Neon или Supabase.
- Каждый запрос проверяется подписью Telegram (HMAC), админ-права определяет сервер по `ADMIN_IDS`.
- Оплаты в приложении нет: заказ уходит админу, дальше вы договариваетесь с клиентом сами.
